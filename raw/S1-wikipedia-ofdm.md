# S1 擷取重點（以自己的話整理）

## 定義
- OFDM 把一條資料流分散到很多個載波上，每個載波的符號率都很低，載波彼此靠得很近。
- 每個子載波各自用一般的調變（QAM、PSK）。在相同頻寬下，總資料率和單載波系統差不多。
- 它是 FDM 的一種，但子載波的頻譜彼此重疊。

## 正交性
- 子載波間距選得讓彼此正交，因此子通道之間沒有串擾。
- 因為正交，不需要保護頻帶，也不需要每個子通道各自的濾波器。
- 間距是有效符號長度的倒數：Δf = 1/T_U。N 個子載波的總頻寬約為 N·Δf。
- 802.11a：1/3.2 µs ≈ 312.5 kHz。

## 為何能對抗多路徑與 ISI
- 每個符號相對於通道的時間擴散很長，等於用很多條慢速資料流取代一條快速資料流。
- 符號之間插入保護區間吸收回音；只要多路徑延遲擴散比保護區間短，就沒有 ISI。
- 例子：1 ms 符號加 1/8 保護區間 = 125 µs，可容忍約 37.5 km 的路徑差。
- 每個窄子載波內的衰落近似平坦，所以等化很簡單。

## 循環前綴
- 保護區間放的是循環前綴：把 OFDM 符號尾端複製到開頭。
- 這讓接收端 FFT 視窗內，每條路徑都包含整數個週期，子載波仍保持正交。
- 代價：保護區間是冗餘資料，會降低容量。

## IFFT/FFT 實作
- 發射端：位元分成平行串流 → 各自對應到 QAM/PSK 符號 → IFFT 得到時域樣本 → 加循環前綴 → DAC、升頻。
- 接收端：降頻 → 濾波、ADC → FFT → 每個子載波各自判斷 → 還原位元。

## 一階（one-tap）等化
- 頻域等化時，每個子載波只要乘上一個複數常數。
- 用導頻（pilot）子載波估計每個子載波的增益與相位。

## 缺點
- PAPR（峰均功率比）高：許多子載波可能同相相加，需要高解析度 DAC/ADC 與線性功率放大器，效率較差。
- 頻率偏移與都卜勒會破壞正交，造成 ICI（子載波間干擾）。
- 需要準確的時間與頻率同步。
- 循環前綴占掉每個符號的一部分時間。

## 歷史
- 1966：Robert W. Chang（Bell Labs）提出 OFDM 概念並取得專利。
- 1971：Weinstein 與 Ebert 提出用 DFT 做調變，並加入保護區間。
- 1995–1999：DAB、DVB-T（1997）、IEEE 802.11a（1999）標準化。
- 2005–2007：LTE 採用 OFDMA。

## 使用 OFDM 的標準
- Wi-Fi：IEEE 802.11a/g/n/ac/ax（ax 加入 OFDMA）。
- 行動通訊：LTE 下行（OFDMA）、5G NR 上下行。
- 廣播：DVB-T/T2、DAB、ATSC 3.0。
- 有線：ADSL/VDSL（DMT）、DOCSIS 3.1。

## IEEE 802.11a 參數表
| 參數 | 值 |
|---|---|
| FFT 大小 | 64 |
| 有使用的子載波 | 52 |
| 有效符號長度 T_U | 3.2 µs |
| 保護區間 | T_U 的 1/4，即 0.8 µs |
| 子載波間距 | 312.5 kHz |
| 通道寬度 | 20 MHz（64 × 312.5 kHz） |
| 子載波調變 | BPSK、QPSK、16-QAM、64-QAM |
| 資料率 | 6–54 Mbit/s |

（備註：本頁未說明 52 個子載波中資料與導頻各幾個。）
