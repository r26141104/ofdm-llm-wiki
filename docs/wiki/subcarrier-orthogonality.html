子載波正交性

類型：concept　來源：S1、S6　前置概念：ofdm-basics

一句話

子載波的頻譜雖然重疊，但只要子載波間距 = 有效符號長度的倒數，在每個子載波的中心頻率上，其他子載波的貢獻剛好是 0。

Δf=1TU\Delta f = \frac{1}{T_U}

直覺

  • 在長度 TUT_U 的時間裡，每個子載波都剛好跑整數圈。兩個不同子載波相乘再積分，正負剛好抵消 → 正交。
  • 頻域上看，每個子載波是一個 sinc 形狀；某個子載波的峰值，正好落在其他所有子載波的零點上。

好處

  • 不需要傳統 FDM 的保護頻帶，也不需要每個子通道各自的濾波器 → 頻譜利用率高。
  • N 個子載波的總頻寬約為 B≈N ΔfB \approx N\,\Delta f。

例子

802.11a：TUT_U = 3.2 µs → Δf\Delta f = 1/3.2 µs = 312.5 kHz。見 實例：IEEE 802.11a 的 OFDM 參數。

什麼會破壞正交

頻率偏移、都卜勒 → 見 載波頻率偏移。
